# EMSELL — готовый проект для Vercel

## Что реализовано
- Тёмный адаптивный дизайн в стиле ваших примеров.
- Игры и плейсы/серверы.
- Регистрация и вход: **почта + пароль**, затем 6-значный код на почту.
- Объявления: название, описание, цена, ₽/₴/$/своя валюта, фото.
- Фото сохраняются в Supabase Storage.
- Профиль, юзернеймы, имена/почты, статус верификации.
- Чат покупателя и продавца, обновление каждые 5 секунд, звуковое уведомление (браузер может требовать первое взаимодействие пользователя).
- Статус «в сети / был недавно».
- Админ-панель: бан, разбан, выдача/снятие галочки, просмотр email.
- Telegram: канал `https://t.me/emsasell`, поддержка `https://t.me/emsellhelpbot`.
- Логотип из предоставленного вами последнего изображения: `public/emsell-logo.jpg`.

## ВАЖНО О ПОЧТЕ
Пароль почты **не хранится в проекте и не должен попадать в Vercel**. Если пароль уже был отправлен в чат, для безопасности смените его. Для отправки кодов используется **Resend**, а не Gmail-пароль. Это безопаснее и подходит для Vercel.

## Деплой БЕЗ терминала

### 1. Создайте Supabase
1. Откройте Supabase и создайте проект.
2. Откройте **SQL Editor**.
3. Создайте New query.
4. Скопируйте и выполните весь файл `supabase.sql`.
5. В Project Settings → API скопируйте:
   - Project URL
   - `service_role` key (НЕ anon key).

### 2. Настройте отправку почты через Resend
1. Создайте аккаунт Resend.
2. Получите API key.
3. Для реального адреса отправителя добавьте и подтвердите свой домен.
4. До подтверждения домена можно тестировать на разрешённом Resend адресе.
5. В `EMAIL_FROM` укажите подтверждённый адрес, например `EMSELL <noreply@вашдомен.ru>`.

> Отправка «с emsamsell@gmail.com» напрямую через пароль Gmail в Vercel не рекомендуется. Gmail требует отдельной SMTP/OAuth-настройки и пароль нельзя безопасно вшивать в код. Если именно Gmail обязателен — настройте почтовый сервис с OAuth или отдельным app password, но храните секрет только в переменных окружения.

### 3. Загрузите проект на Vercel
Самый простой способ без терминала:
1. Создайте пустой GitHub repository через сайт GitHub.
2. Загрузите содержимое этой папки в репозиторий через **Add file → Upload files**.
3. На Vercel нажмите **Add New → Project → Import Git Repository**.
4. Выберите репозиторий EMSELL.
5. В **Environment Variables** добавьте значения:

`SUPABASE_URL` = URL из Supabase  
`SUPABASE_SERVICE_ROLE_KEY` = service_role key  
`RESEND_API_KEY` = API key Resend  
`EMAIL_FROM` = подтверждённый отправитель  
`JWT_SECRET` = длинная случайная строка (минимум 32 символа)  
`ADMIN_EMAIL` = почта администратора

6. Нажмите Deploy.

### 4. Сделайте себя администратором
Зарегистрируйтесь именно с почтой, указанной в `ADMIN_EMAIL`, подтвердите код и войдите. Админ-панель появится в шапке.

## Безопасность
- Не публикуйте `SUPABASE_SERVICE_ROLE_KEY`, `RESEND_API_KEY`, JWT secret или пароль почты.
- В проекте есть `.env.example`, но реальные значения добавляйте только в Vercel.
- Перед запуском обязательно смените любой пароль, который уже отправляли в переписках.
- Площадка является доской объявлений: добавьте собственные правила, модерацию и юридическую информацию перед публичным запуском.
